# Notebook-Todolist
笔记、待办、复习卡合为一体的学生学习笔记应用 | Flask + SQLite + 原生 JS

核心理念：**笔记、待办、复习卡是同一份内容的不同视图。**

## 本地运行

需要 Python 3.12。

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
python app.py
```

默认监听本机 5000 端口。数据库和上传目录在被 Git 忽略的 `instance/` 中。
`SECRET_KEY`、`DATABASE_PATH`、`TZ` 等配置从环境变量读取；`.env` 只用于本地配置，禁止提交。

## 当前功能

- 一周课表、按当前课程自动分类笔记，也可手动调整。
- Markdown 编辑和安全渲染，课程筛选与全文搜索。
- `- [ ]` 自动提取待办，默认在该课程下一节课截止。
- `==重点==` 自动生成挖空卡，按 1/3/7/15 天复习，遗忘后重置。
- 今日页汇总到期和过期待办、复习卡；移动端和深色模式。
- 一键随手记、本地草稿恢复、纸张/夜读两套分享长图、PWA 主屏幕安装。
- 用户名密码注册登录、按用户隔离数据、CSRF 与持久化登录失败限速。
- OpenAI 兼容 AI：笔记整理、自然语言待办、问答卡、板书识别；结果确认后保存。
- LaTeX 公式渲染，照片压缩后识别，原图作为私有附件保留。

## AI 配置

登录后打开「设置」，填写 Base URL、API Key 和模型名。默认示例为 DeepSeek / `deepseek-v4.1-flash`。
Key 仅保存于此浏览器的 localStorage，随请求头临时转发，不写入后端数据库、配置或日志。
自定义服务需要管理员在 `AI_ALLOWED_HOSTS` 中加入其域名；仅支持公网 HTTPS 443，不访问内网和重定向地址。
照片识别需要该服务商提供支持图片输入的模型。生成结果必须核对；任务日期可在确认前手动更正。

## Known Issues

- 待办完成状态暂不反向修改笔记中的 Markdown 复选框。
- 草稿仅在当前浏览器中保存；完整离线编辑与跨设备同步尚未实现。
- 第一、二阶段无登录版本的本地数据不会自动分配给新注册用户，避免误认领。
- AI 转发及交互已用模拟服务测试，尚未使用真实 API Key 验证供应商模型和识别质量；默认模型名为可修改示例。
- 分享图单篇限 12000 CSS 像素高度，超长笔记请拆分；原图附件需在刷新前完成上传。
